# Александр и Яна — 30 января 2027

Готовое одностраничное свадебное приглашение на React, TypeScript, Tailwind CSS и Framer Motion. Сохранены молочный фон, элегантная типографика, непрерывная вертикальная композиция и тёмный финальный блок. Цветочная иллюстрация взята из файла невесты без перерисовки.

## Данные свадьбы

- Александр и Яна.
- 30 января 2027 года. Сбор гостей в 16:00, местное время Перми.
- Банкетный зал AurA Grand Hall, г. Пермь, ул. Куйбышева, 66.
- Ответ на приглашение — до 15 января 2027 года.
- Анкета: имя и фамилия, подтверждение присутствия, поле «Придёте не одни?» (скрывается при отказе от участия).
- Обратный отсчёт убран. Отдельная программа вечера не добавлялась.
- В тёмном блоке — завершение приглашения от пары, без контактов из референса.
- После локации расположен раздел подтверждения присутствия.

Данные редактируются в `src/config.ts`. Все изображения и шрифты локальные; сторонние CDN для оформления страницы не нужны.

## GitHub Pages — загрузка готового сайта

Используйте архив `alexander-yana-30-01-2027-github-pages.zip` из родительской папки проекта. Распакуйте его и загрузите **содержимое** в корень репозитория:

```text
index.html
assets/
rsvp-config.json
.nojekyll
```

В GitHub откройте **Settings → Pages → Deploy from a branch → main → / (root) → Save**. Не загружайте сам ZIP вместо распакованных файлов. Сайт работает и в корне домена, и по адресу вида `https://username.github.io/repository/`.

Файл `rsvp-config.json` содержит публичный адрес приёмника ответов:

```json
{
  "endpoint": "https://script.google.com/macros/s/ВАШ_ID/exec"
}
```

Адрес можно добавить или изменить непосредственно в этом JSON на GitHub **без пересборки сайта**. Пустой адрес отключает отправку и показывает гостям, что приём ответов ещё не открыт. Ложного подтверждения отправки нет.

## Google Таблица ответов

Создана отдельная [Google Таблица «Александр и Яна — ответы гостей — 30.01.2027»](https://docs.google.com/spreadsheets/d/1SNCV-6v_oQg4MJ5gU1Pk01lxHiMwcgHGO7KotSsX_Ok/edit).

Столбцы: дата ответа, имя и фамилия, присутствие, сопровождающие, дата свадьбы, технический ID ответа. Таблица остаётся закрытой; посетителям не выдаётся доступ к её строкам.

[Проект Google Apps Script](https://script.google.com/u/0/home/projects/1lguRCTSoGxBHBbGkBV7x-v8SZLb5re3_aQxXumG5Ms1oA9XogsONbF7H/edit) уже содержит обработчик из `integrations/google-apps-script/Code.gs` с ID созданной таблицы.

**Подключение активно.** Обработчик опубликован, адрес уже указан в `public/rsvp-config.json`. Проверена настоящая отправка из анкеты и появление строки в таблице. Для публикации на GitHub Pages дополнительных действий в Google не требуется.

Если потребуется заново создать подключение:

1. В редакторе Apps Script выполните `setupRsvp` и самостоятельно подтвердите запрашиваемые Google разрешения. Новый личный скрипт может вызвать предупреждение о непроверенном приложении; решение о предоставлении доступа принимает владелец аккаунта.
2. Откройте **Начать развёртывание → Новое развёртывание → Веб-приложение**.
3. Выполнять от имени: **вас**. Доступ: **Все** — чтобы гости могли отвечать без входа в Google. Это открывает только приёмник и проверку статуса, а не доступ к самой таблице.
4. Скопируйте URL, заканчивающийся на `/exec`, в `rsvp-config.json`.
5. Отправьте одну тестовую анкету и проверьте новую строку в таблице.

При изменении серверного кода обновите версию существующего развёртывания через управление развёртываниями. Само сохранение файла Apps Script не обновляет опубликованный `/exec`.

### Как подтверждается сохранение

Сайт отправляет JSON через POST `text/plain`, совместимый с ограничениями Apps Script и GitHub Pages. Ответ `no-cors` не считается успешной отправкой. Затем сайт проверяет наличие сохранённого случайного ID через отдельный JSONP-запрос. Этот запрос возвращает только ID и статус, не раскрывая имён и ответов гостей.

Обработчик проверяет данные, записывает строку, вызывает `SpreadsheetApp.flush()` и только затем подтверждает запись. Повторная попытка с тем же ID не создаёт дубль. Изменение данных анкеты создаёт новый ID. При отказе от участия сопровождающие не записываются. Текст, начинающийся со знака формулы, сохраняется как обычный текст.

При ошибке или отсутствии подтверждения сайт сохраняет введённые поля в открытой форме и предлагает повторить отправку. Успех показывается только после подтверждения записи.

Техническая основа: [веб-приложения Apps Script](https://developers.google.com/apps-script/guides/web), [Content Service и JSONP](https://developers.google.com/apps-script/guides/content).

## Локальный запуск и пересборка

```sh
pnpm install
pnpm dev
```

```sh
pnpm test
pnpm build
pnpm preview
```

Сборка находится в `dist/`. Для локального просмотра используйте HTTP-сервер, а не двойной щелчок по HTML. JSON с адресом обработчика копируется в сборку автоматически.
